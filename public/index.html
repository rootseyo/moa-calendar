연결 전 준비

Apple 앱 암호 발급하기

앱 암호는 모아에서 iCloud 캘린더에 접근할 때 사용하는 전용 암호예요.

  1. Apple 계정에 로그인

    account.apple.com ↗에 접속해 캘린더를 사용하는 계정으로 로그인하세요.

  2. 로그인 및 보안 → 앱 암호

    계정 설정에서 ‘앱 암호’를 선택하세요. 앱 암호를 만들려면 이중 인증이 켜져 있어야 해요.

  3. 앱 암호 생성

    ‘앱 암호 생성’을 선택하고 이름을 ‘모아 캘린더’로 입력한 뒤 화면의 안내를 따라주세요.

  4. 발급된 암호로 연결

    발급된 암호를 복사해 ‘Apple 앱 암호’ 입력란에 붙여넣으세요.

앱 암호가 보이지 않거나 연결이 안 되나요?

Apple 계정의 이중 인증을 먼저 확인하세요. 계정의 기본 암호를 변경하거나 재설정했다면 기존 앱 암호가 모두 취소되므로 새로 발급해 연결해야 해요.

앱 암호를 삭제하려면 Apple 계정의 ‘로그인 및 보안 → 앱 암호’에서 해당 암호를 제거하세요.
